# 6-DOF-Modular-Robotic-Arm
An end-to-end open-source robotics project featuring custom-designed 3D CAD models (PTC Creo Parametric), embedded servo drive integration, ROS 2 dynamic control, and Python-based trajectory/kinematics scripts.
